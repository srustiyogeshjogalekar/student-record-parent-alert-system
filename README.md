# Student Sphere

**Student Record and Parents Alert System**

A simple web-based system to manage student records and send important alerts to parents.

## Features

* Student record management
* Parent details
* Attendance management
* Marks management
* Parents alerts
* Important notifications

## Objective

To maintain student records digitally and keep parents informed about student attendance and academic activities.
